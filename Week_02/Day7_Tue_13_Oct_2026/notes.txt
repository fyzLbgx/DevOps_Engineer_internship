SSH is secure shell protocol a network protocol  that allow us to connect and control a remote computer
over network. ssh is  secured encrypted and also support functions like file transfer
it use client server model and run on port 22. 

it support 2 authentication methods pasword and keybased by using public private keypair

there are tools built on top of ssh that support file transfer like scp and sftp 

sftp is intractive unlike scp
